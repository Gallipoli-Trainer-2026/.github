## Troubleshooting

**Menu not opening**
- Run as Administrator
- Disable antivirus or add exception
- Verify game is running in windowed or borderless mode

**ESP not showing**
- Check if overlay is enabled
- Disable Discord overlay
- Update GPU drivers

**Game crash**
- Disable speed hack
- Lower overlay resolution
- Restart trainer and game
